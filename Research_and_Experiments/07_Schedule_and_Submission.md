## Rules for sharing time and computers

- Give P0 work first use of resources when jobs compete for them, while independent P1/P2 checks continue.
- Measure a small G03 trial before estimating time or cost. Clearly label any later forecast as a forecast.
- Reuse reference runs and saved outputs only when the test conditions match. Change one part in each comparison; several comparisons can run together.
- Keep every item listed with a real result or a clear unresolved status. An experiment that cannot start is neither completed nor rejected because of poor performance.
- Keep time for final testing, repeating the work, and submission before starting a run that would finish too late.
- Do not assume that running jobs together on one GPU increases processing speed, or that free notebook services provide GPUs that can be combined for one job.

## Submission package

Verified requirements and recommendations are summarized here; use the full [official overview](https://www.kaggle.com/competitions/ai-4-s-open-innovation-artificial-intelligence-for-life-scien/overview#submission-requirements) and [rules](https://www.kaggle.com/competitions/ai-4-s-open-innovation-artificial-intelligence-for-life-scien/rules) for the final check.

- Declare one category at the start of the Kaggle Writeup.
- Include a public demonstration video, public code, and a technical report.
- Keep the video within five minutes and accessible without login or payment.
- Show actual inputs, how the tool works, outputs, and examples of how it handles failures.
- Provide the software setup, data/model access instructions, the command or file that starts evaluation, and exact steps to repeat the work. Reviewers need an accessible way to do this without paid services, special company-controlled hardware, or data that is not public.
- Disclose earlier work, data/model-file/code sources, usage rights, and important help from AI tools.
- Check the separate registration form and entry requirements. The task's browser showed that Kaggle rules were accepted, but this does not prove separate registration was completed.
- The organizer recommends a 200 to 300 word summary and a report that can be understood on its own, ideally within 15 to 20 pages excluding references/appendices. Use only as much space as the evidence needs.
