# Results vs what each experiment had to beat (7 Oct 2026, 12:45 IST) — after following improvements.md

**How to read this.** Same format as [13_Results_vs_Expected_6_Oct.md](13_Results_vs_Expected_6_Oct.md), updated after the improvement round in [improvements.md](improvements.md). No fixed pass marks were set in advance (user rule), so "had to beat" is the reference number for the same test: the simpler method, the "without it" version, or chance. "Enough?" is **Yes** only when the gain is clear (a 95% interval that excludes 0 where one was computed, or a large, consistent gap); otherwise it says what is still needed. All paths are relative to the project folder `AI4S/`.
Scores: **AUC** = chip-photo ranking grade (0.5 = coin flip, 1 = perfect, higher is better); **count error** = nuclei per image the count is off by (lower is better); **F1@0.75** = outline match at strict overlap (higher is better).

**Most tests have saved results, but not every task is finished.** C04 is blocked; R02 to R04 were re-scored under a repaired evaluation on 8 October ([review](Evidence/2026-10-07_RL_scoring_review.md), [result](Evidence/2026-10-08_RL_repaired_evaluation.md)); F03 covers a limited rebuild; F04 is incomplete. Use [the final consolidated status of all 36 IDs](22_Final_Results_Before_and_After.md#section-4-consolidated-status-of-all-36-original-ids). The R02 to R04 rows below carry the repaired numbers.
**Compute:** Modal stopped; everything since 22:35 on 6 Oct ran on Kaggle's free GPUs ($0). Modal's bill reads $17.08 now (it read $24.26 last night; not reconciled, so no more Modal use).
