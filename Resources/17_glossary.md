# Short word guide

| Word | Simple meaning |
|---|---|
| Organ-on-a-chip / OoC | A small lab device that grows living cells under controlled conditions |
| Nucleus | The part of a cell that contains most of its DNA |
| Segmentation | Marking separate objects or regions in an image |
| Mask | An image that marks which pixels belong to an object; pixels are the tiny dots that make up an image |
| Phenotype | A cell's appearance or behavior that can be observed |
| Channel | One image signal recorded separately, often from one stain used to make cell parts visible |
| Metadata | Details about a sample, such as its treatment or lab run |
| Baseline | A simple method used for comparison |
| Training | Teaching a model using examples |
| Validation | Checking examples to help choose model settings |
| Test set | Examples kept aside for the final check |
| Batch effect | A difference caused by lab conditions rather than the biology being studied |
| Leakage | Information from the test examples accidentally affecting training or the choice of model |
| Synthetic data | Artificial data made by a program |
| Pretrained model | A model already taught using another collection of examples |
| Fine-tuning | Further training an existing model |
| Ablation | Removing one component to test whether it helps |
| Reproducible | Someone else can follow the instructions and get comparable results |
| GPU / CPU | A processor that speeds up some AI training / the computer's general-purpose processor |
| U-Net | An AI model commonly used to label the pixels, or tiny image dots, in an image |
| Watershed | An image method that can split touching objects |
| Seed | A number that helps repeat a program's random choices |
