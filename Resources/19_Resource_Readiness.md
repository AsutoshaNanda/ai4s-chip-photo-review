## Findings that change the plan

**C03 now has a specific data lead.** Allen's training-data page gives the paired-image experiment a better starting point. Its [terms](https://www.allencell.org/terms-of-use.html) restrict certain uses and sharing, including posting content on third-party sites that require ownership declarations. Check these terms against the intended report/video/code submission. This update does not establish that the final sharing plan is allowed. This microscope-image dataset also does not become a test of chip quality.

**Already-trained nucleus models need a check for prior exposure.** StarDist identifies two fluorescence models trained with DSB 2018 data, while BBBC039 confirms some shared images with BBBC038/DSB. Cellpose's current README still has a CC-BY-NC training-data notice. InstanSeg's guide requires a pixel size to be supplied if it is missing from the image details. These are source facts, not proof that every saved model is either unusable or safe to use. [StarDist](https://github.com/stardist/stardist), [BBBC039](https://bbbc.broadinstitute.org/BBBC039), [Cellpose](https://github.com/MouseLand/cellpose), [InstanSeg](https://github.com/instanseg/instanseg)

**Do not repeat old download sizes without identifying the exact file.** The rechecked RxRx1 page describes a large original collection. The earlier guide's 51 MB feature-table and 45 GB image sizes were not confirmed for a chosen file today. They are removed from the current download recommendation. Different formats can have different sizes; this does not show that the provider made an error.

## Proposed ways to get more evidence from the same work

These are suggestions for how to do the work. They are not measured time savings or expected score improvements.

1. **Save fixed image features for reuse.** These are image measurements produced by a model whose learned settings stay unchanged. Reuse them for A02's simple category model, A07's comparison using sample details, and suitable A11 comparison methods. The saved file's identity must include the source image, training/test group, data-preparation steps, and fixed model files. Further training changes the model that makes these features, so the saved features can no longer be reused this way.
2. **Study saved predictions while another model trains.** A08/A09/A10 and B05/B06 often use saved outputs. Claim time savings only after measuring the actual workflow.
3. **Use small tables of cell measurements for C01/C02 when checked.** Do not commit to full microscope-image archives before establishing the table-based task and where the table came from. Even a small table needs checks of sample groups and data preparation.
4. **Compare independent changes with one matching reference run.** Share a reference only when the data, random seed, settings, and scoring match. A seed is the number used to repeat random choices. Test combined changes after learning each change's effect.
5. **Start the report and demo layout during setup.** Leave result fields empty until measurements exist. A small entry that runs helps ensure we can submit while other experiments continue.
6. **Rent for a measured need.** Compare the full run cost using memory and time measured in a small trial and an actual offer. The provider list and cost fields are in [the computing guide](08_tools_and_free_compute.md).
