# Experiment log: use the central record

Updated: **2 October 2026**. No model runs or model outputs were found in the checked project folder. This does not tell us whether work exists elsewhere. Blank measurements mean not measured, not zero.

Record every actual run in [the central experiment log](../Research_and_Experiments/08_Run_Log.md), using the IDs from [the complete schedule](../Research_and_Experiments/10_All_Experiments_Parallel_Schedule.md). Keeping one record avoids duplicate score tables that disagree.

All the earlier E0 to E6 experiments have matching entries in that schedule. The old blank template is kept in [the copy saved before the update](../Research_and_Experiments/Evidence/plans_before_2026-10-02.zip).

For each run, record the data/version and training/test groups, what changed in the method, settings and code version, computer and time taken, each sample's output, overall and per-group measurements, failures, evidence quality, the decision that changed, and the next test. Save real failed outcomes too. Never put a paper's or participant's score in the column for our measured results.
