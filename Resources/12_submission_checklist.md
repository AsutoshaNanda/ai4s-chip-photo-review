# Submission checklist

Source: [official submission requirements](https://www.kaggle.com/competitions/ai-4-s-open-innovation-artificial-intelligence-for-life-scien/overview#submission-requirements), rechecked 2 October 2026 in the live browser.

## Required

- [ ] Required registration form completed; confirmation saved privately.
- [ ] Team details checked, including whether the team meets entry requirements.
- [ ] One category declared at the top of the Kaggle Writeup.
- [ ] Public video shows actual inputs, operation, and outputs.
- [ ] Video is at most 5 minutes; no login, payment, or access request needed.
- [ ] Public code link works.
- [ ] Code includes a README guide, software setup, data instructions, model files or download steps, and instructions for starting tests and the demo.
- [ ] Reviewers can repeat the work without paid services, special company-controlled hardware, or datasets that are not public.
- [ ] Technical report included directly or through a public PDF link.
- [ ] Data, models, software libraries, AI tools, usage rights, and earlier work listed and credited.
- [ ] Results, failures, limits, and instructions for repeating the work included.

The organizer suggests a **200–300-word project summary** and a self-contained report ideally within **15–20 pages**, excluding references and appendices. These are recommendations, not a reason to pad the report.

## Our final checks

- [ ] Re-run from a clean setup.
- [ ] Every number we claim can be traced to saved results.
- [ ] Report each tested method, important group, and worst failure.
- [ ] Clearly separate computer-made data, public microscope-image data, and real-chip evidence.
- [ ] Check links in a signed-out browser.
- [ ] If using an optional live demo, include a backup video and local run instructions.
- [ ] Record the final decision in [the central evidence log](../Research_and_Experiments/06_Evidence_and_Decisions.md).
- [ ] Give each of the 36 planned items a status: measured, rejected, or clearly unfinished. Do not claim that checking data means a model test is complete.
- [ ] Confirm the Writeup is submitted, not merely saved as a draft.
